# Legacy Minecraft 1.18 data

This branch restores immutable Bedrock data snapshots required by the EraseMC Minecraft 1.18 compatibility profiles.

- `1.18.0`: canonical block states, legacy block map, required item list
- `1.18.10`: canonical block states, legacy block map, block-to-item map, required item list
- `1.18.30`: canonical block states, legacy block map, block-to-item map, required item list

The files originate from the historical PocketMine BedrockData commits which originally supported these releases. Do not regenerate them with a newer Bedrock Dedicated Server.
